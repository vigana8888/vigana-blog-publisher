# 비가나스쿨 네이버 블로그 자동화 프로젝트

키워드를 주면 비가나스쿨 블로그 톤에 맞는 글(3부작 시리즈)과 이미지 프롬프트를 자동으로 생성하고, 초안을 검토한 뒤 네이버 블로그에 예약발행하는 워크플로우.

## 폴더 구조

```
vigana-blog-publisher/
├── STYLE_GUIDE.md          # 톤앤매너·구조·분량 규칙 (모든 생성 작업의 기준)
├── topics_log.md           # 지금까지 다룬 주제 이력 (중복 방지용)
├── drafts/                 # 생성된 글 초안 (마크다운, 사람 검토 후 게시)
├── .venv/                  # Python 가상환경 (Playwright 실행용)
├── scripts/
│   ├── login_setup.py      # 최초 1회 실행 — 네이버 수동 로그인 후 세션 저장
│   └── save_draft.py       # drafts/의 글을 네이버 에디터에 채워넣고 임시저장
├── naver_session.json      # 로그인 세션 (git에 올리지 않음, login_setup.py가 생성)
├── .env                    # BLOG_ID 등 로컬 설정 (git에 올리지 않음, .env.example 참고)
└── .claude/commands/
    └── blog-series.md      # /blog-series 커스텀 명령 — 주제 리서치~3부작 생성 자동화
```

## 사용법

이 폴더에서 Claude Code를 열고 실행한다.

- `/blog-series` — 주제를 자동으로 리스트업해서 새 3부작 시리즈를 생성
- `/blog-series 바이올린 활 잡는 법` — 주제를 직접 지정해서 바로 3부작 생성

생성된 글은 `drafts/`에 저장되며, 이미지는 아직 비어 있는 상태로 프롬프트만 함께 제공된다. 검토 후 직접 이미지 삽입 → 네이버 블로그에 게시한다.

## 현재 단계 (Phase 1 — 완료)

- 실제 블로그 글 3편을 기반으로 톤앤매너 분석 → `STYLE_GUIDE.md` 완성
- 키워드 기반 3부작 생성 워크플로우를 `/blog-series` 명령으로 구조화

## 현재 단계 (Phase 2 — 네이버 임시저장 자동화, 구축 완료 / 실사용 검증 필요)

Playwright 스크립트가 준비되어 있다. 실제 발행이나 예약발행은 하지 않고 **임시저장까지만** 자동화한다 — 이미지 삽입과 최종 발행/예약 설정은 네이버 에디터에서 직접 한다.

비밀번호는 어떤 파일에도 저장하지 않는다. 최초 1회만 실제 브라우저 창에서 직접 로그인하고, 그 로그인 세션(쿠키)만 로컬 `naver_session.json`에 저장해 재사용한다.

### 실행 순서

```powershell
# 1. .env 파일 만들기 (최초 1회)
copy .env.example .env
# .env를 열어서 BLOG_ID가 본인 블로그 아이디(erumgamsa)로 되어 있는지 확인

# 2. 로그인 세션 저장 (최초 1회, 또는 세션 만료 시 재실행)
.venv\Scripts\python.exe scripts\login_setup.py
# 브라우저 창이 뜨면 직접 로그인 -> 완료되면 터미널에서 Enter

# 3. 원하는 초안을 네이버 블로그에 임시저장
.venv\Scripts\python.exe scripts\save_draft.py drafts\파일명.md
```

### 주의 — 실사용 전 검증 필요

네이버 블로그 도메인은 Claude가 직접 열람할 수 없는 곳이라, `save_draft.py`의 정확한 버튼/입력창 선택자는 실제로 테스트해보지 못한 상태다. 처음 실행할 때는 브라우저 창이 보이는 상태(headless 아님)로 동작하므로, 제목/본문이 제대로 들어가는지, "저장" 버튼이 정확히 눌리는지 직접 확인해야 한다. 오류가 나면 화면에 뭐가 보이는지 알려주면 선택자를 수정한다.

네이버 이용약관상 자동 게시는 공식 지원 대상이 아니므로, 완전 무인 발행이 아닌 임시저장까지만 자동화하고 최종 발행은 항상 사람이 직접 확인 후 진행한다.

## 선택 사항 — 네이버 검색 API 연동

`/blog-series`의 1단계(키워드 리서치)를 더 정확하게 하고 싶다면, developers.naver.com에서 무료로 애플리케이션을 등록하고 "검색" API(블로그) 권한을 받아 Client ID/Secret을 발급받는다. 발급받은 값은 채팅에 붙여넣지 말고 이 폴더에 `.env` 파일을 만들어 아래처럼 넣어둔다.

```
NAVER_CLIENT_ID=발급받은값
NAVER_CLIENT_SECRET=발급받은값
```

`.env`는 없어도 `/blog-series`는 정상 동작하며, 없으면 일반 웹 검색 결과만으로 리서치를 진행한다.
